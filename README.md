# Altrion Advisory

Independent FM strategy and commercial advisory website.

## Development

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the development server
- `npm run build` — production build
- `npm run preview` — preview the production build
- `npm run lint` — run ESLint

## Stack

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Motion
